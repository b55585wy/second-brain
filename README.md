# 第二大脑

知行是一款以降低认知负荷为目标的本地学习工具。当前本机已部署 **本地单用户 Beta（0.5.1）**：后台按目标整理已授权对话，首页直接给出独立输出练习，可选 AI 点评帮助确定下一步；飞书私聊与网页共用回答记录。原有项目、知识、思源复习和手动采集保留在高级工具中。

0.4.0 已完成完整回归、本机升级、一次既有回答的真实 DeepSeek 点评，以及当前学习卡片的真实投递和按钮回调确认；思源 3.8.9 的独立真实 HTTP 验收和本机连接检查通过。见 [回答建议验收及后续补记](docs/ANSWER-ADVICE-VERIFICATION-20261030.md)、[按钮说明](docs/FEISHU-LEARNING-CARDS.md)和[思源验收](docs/SIYUAN-389-VERIFICATION-20261030.md)。云端发布状态以 GitHub Release 为准。

**0.5：先讨论，再保存。** 可以针对建议追问或要求修改，满意后才点击保存当前版本；原回答、原点评及已保存版本保留。0.5.1 调整为先讲解，允许用户请求完整参考示例，无需先作答才得到帮助；保存时一并收藏本轮讲解。用户已完成一轮真实讨论，明确保存仍待用户操作，新教学方式尚未经过真实模型验证。此能力主要在飞书卡片和引用回复中使用，不增加独立聊天页面。测试、部署及验收边界见 [讨论说明](docs/ADVICE-DISCUSSION-API.md)和[0.5验收记录](docs/ADVICE-DISCUSSION-VERIFICATION-20261031.md)。

**日常只需打开「今天」，看重点，写输出。** 档案、对话范围和模型配置一次即可开启自动整理。详见 [使用 SOP](docs/DAILY-SOP.md) 与 [简化目标](docs/SIMPLICITY.md)。旧手动版已固定为 [实验对照 Release](https://github.com/b55585wy/second-brain/releases/tag/control-manual-v0.1.0-20261028)；[CHI 研究草案](docs/CHI-RESEARCH-PLAN.md)区分了产品验收与尚待验证的研究结论。

开发计划：[短期迭代计划](docs/NEXT-ITERATION.md) · [产品路线图](docs/ROADMAP.md)。源码实现、验收与部署分别记录，当前状态见 [实施状态](docs/IMPLEMENTATION-STATUS.md)。

## 从源码初始化

仓库保存源码、依赖锁文件、测试和文档。个人数据库、凭据、对话快照、思源工作区、安装包和生成产物保留在本机，不随 Git 提交。下文的已连接状态指当前已验收的本机部署；克隆源码后需要重新构建和配置。[脱敏验收摘要](docs/verification/2026-10-28.json)随源码保存，原始日志与截图仅在原机器保留。

安装 Windows 和 Node.js 24.22.0 或更高版本后，在仓库根目录执行：

```powershell
npm.cmd ci
npm.cmd --prefix frontend ci
npm.cmd run build
npm.cmd test
.\start.cmd --check
```

手工编辑、模板计划与练习可以直接使用。0.4 源码的原生复习支持精确版本 **思源 3.8.8、3.8.9**，请在自己的全新工作区配置连接；凭据只在本机填写。`open-siyuan.cmd` 当前指向已验收的 `runtime/zhixing1c2af369`，其他机器应先创建自己的工作区并调整该入口路径。运行说明中的本机连接清单不在仓库内，不能把示例文件当作已验证的真实连接。

## 启动

0.3.3 起，思源升级到尚未验证版本只提示警告，不阻断知行与飞书后台；思源同步和原生卡片评分仍保留兼容性检查。见 [启动修复验收](docs/STARTUP-VERSION-VERIFICATION-20261030.md)。

需要 Windows、Node.js **24.22.0 或更高版本**和已构建的前端。当前本机日常双击桌面的 **知行学习工作台**；源码目录也可双击 **[start-all.cmd](start-all.cmd)**。入口检查并补起专用思源与知行，再打开网页；已运行的服务直接复用。思源入口使用官方 --workspace/--port 参数固定 **19006**。

首次启动知行时保持运行窗口开启，成功监听后自动打开 <http://127.0.0.1:18997>；按 **Ctrl+C** 停止。如果复用已有知行服务，本次入口打开网页后退出，原运行窗口继续负责服务。关闭浏览器页面不会退出后台。浏览器未能打开时可手动访问上述地址。启动器不安装依赖、不注册系统自动启动；缺少前端产物时会提示先构建。需要单独控制时仍可使用 [open-siyuan.cmd](open-siyuan.cmd) 和 [start.cmd](start.cmd)。

## 第一次使用

1. 双击桌面的 **知行学习工作台** 或源码目录的 **start-all.cmd**，打开 <http://127.0.0.1:18997>。保持知行前台窗口开启，Ctrl+C 停止知行；思源通过自己的界面正常退出。日常运行不需要 Kimi CLI 或 codeagent。
2. 在 **偏好设置 → 学习档案** 保存目标、职业方向、技能和每日时间预算；已有档案继续使用。预算为 0 时不安排练习。
3. 在 **高级工具 → 对话采集** 按标题选择需要整理的对话，点击 **保存所选对话**。这是一次性的读取范围授权，排除规则仍然优先。
4. 在偏好设置中配置模型并允许处理所选材料。本机已配置好时直接沿用；自动目标提炼需要有效模型，手工功能仍可独立使用。
5. 回到 **今天** 点击 **开启自动整理**。以后采集和长会话续页在后台完成；每天看少量目标相关重点，在同页独立作答并点 **保存输出**，自查提示可按需展开。后台只在程序运行时工作。

## 可选连接

**自动提炼需要模型。** 在偏好设置中填写兼容接口、模型名及自己的凭据，并明确允许外部处理。自动整理正常间隔一小时，每天至多尝试三次；连接失败允许一次短暂重试，失败和状态不明均计入额度。未配置模型时仍保留高级手工编写、导入及模板计划与反馈。

**0.4 可选自动点评。** 沿用已配置模型，开关默认关闭，开启后的初始上限为 3 次/天，可设 0–20 次；与自动提炼额度分开。新回答保存后准备简短建议，网页与飞书共用结果；失败和结果不明计入次数，不隐式修复重发。查看已有建议、保存建议为现有成果、暂不采纳和原生闪卡复习不额外调用模型。建议不是事实核验或能力掌握证明。

**SiYuan 已连接并通过真实验收。** 专用工作区为 runtime/zhixing1c2af369，回环服务为 **http://127.0.0.1:19006**。使用 open-siyuan.cmd 打开该工作区；从思源工作空间菜单另行打开可能分配随机端口，若发生此情况，先正常关闭该独立窗口，再使用固定端口入口。原有 notes 工作区继续保留。

本产品 **设置 → 思源笔记** 默认勾选 **使用本地运行时连接清单**；当前已提供经实际验证的 runtime/connection.json，并且连接检查已通过。保持此模式即可。当前本机服务允许空令牌，未读取或保存真实 API 令牌；如你另行配置了认证，在本机填写凭据，不发到聊天。手动模式仍可使用：取消勾选后填写实际回环地址，保存思源配置，再检查连接。详细说明见 [运行说明](runtime/RUNBOOK.md)。

**飞书学习入口可选。** 在偏好设置使用扫码流程配置应用，连接后获取一次性绑定码，在机器人私聊中完成绑定。机器人发送现有今日练习，回答直接保存为网页中的同一次练习记录；提醒和本地自查不调用模型。程序须持续运行；扫码保存应用不代表权限和发布已经生效，详见 [接入说明](docs/FEISHU-CHAT.md)。授权文档导入仍可通过高级配置使用。内置自由聊天、学习进度 AI 分析和自适应学习见 [长期路线](docs/CHAT-CHANNEL-DIRECTION.md)。

0.4 的 **扫码启用学习卡片** 为现有机器人补充按钮回调，保留私聊绑定；本机已确认当前卡片送达及真实按钮回调，无需每天重复扫码。卡片支持回答、查看建议、保存或暂不采纳、进入思源记忆闪卡。0.5 新增“继续讨论”，每轮 AI 回复与点评共用现有日额度；发送“OK”、查看已有结果和明确保存均不额外调用模型。

## 数据保存

本产品数据保存在项目内 `data/`：`second-brain.sqlite` 保存设置、项目、来源快照、知识、练习/输出及作业；`data/secrets/credentials.json` 保存本机连接凭据。停止服务后仍保留数据，凭据不应分享或提交。

SiYuan 笔记保存在你手动选择的独立工作区，建议使用全新的 `runtime/workspace`。本产品通过 API 操作明确授权的应用笔记本，不直接修改 SiYuan 内部文件。产品 JSON 导出不包含凭据，也不代替 SiYuan 工作区备份。

## 开发检查

根包使用锁定版本的飞书官方 SDK 与本地二维码库，先运行根目录的 `npm.cmd ci`；前端依赖在 `frontend/` 安装。PowerShell 使用 `npm.cmd`，无需更改执行策略。

| 命令 | 用途 |
| --- | --- |
| `npm.cmd start` / `npm.cmd run server` | 直接以前台方式运行 `server/main.mjs`，不自动打开浏览器 |
| `npm.cmd run build` | 构建前端到 `frontend/dist` |
| `npm.cmd run test:packaging` | 仅验证根清单和启动保护逻辑 |
| `npm.cmd run test:backend` | 运行 `tests/backend/` 的真实 Node 测试 |
| `npm.cmd run test:frontend` | 运行前端 Vitest 测试 |
| `npm.cmd test` | 依次运行打包、后端和前端测试 |
| `npm.cmd run typecheck` | 前端 TypeScript 检查 |
| `.\start.cmd --check` | 只检查启动条件，不启动服务 |
