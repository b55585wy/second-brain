# Codex 长会话续采验证（2026-10-28）

旧采集器要求先在单次分页额度内读完一条对话，超过二十页便报错，尚未写入来源。现在每次读取有界批次，把来源、批内偏移、原生游标和上下文来源 ID 同事务保存；未读完时返回 `hasMore=true`，下一次同步接续。

前端由实际 Kimi CLI 完成，Codex 审查并集成。成功的 Codex 同步且 `result.hasMore === true` 时显示 **本批完成（还有更多）** 和 **继续采集**。按钮复用已保存授权和原有同步守卫，不自动循环；刷新页面或重启服务后，点击 **同步授权对话** 同样可以接续。

无原生消息 ID 时，来源身份使用整段扫描的条目位置和内容摘要；这保证分页切分改变时身份稳定，不代表能识别任意插入、删除或重排后的无 ID 消息。真实对话仅验证了一个有界批次，未声称已经完成全部历史。采集保持本地摘录，结果为未审核草稿，不调用外部模型进行语义分析。

## 测试隔离与恢复

本次开发中，旧测试辅助函数允许 `root: undefined` 覆盖临时根目录，导致合成测试数据及配置进入工作库。已停止相关程序，保存受保护快照，按来源身份核对并清理合成记录，恢复原授权与模型凭据；原有学习记录逐条校验一致，没有真实知识被覆盖。

共享测试辅助函数现在在创建应用前解析并检查根目录、数据目录、数据库和凭据路径。它们必须严格位于物理测试临时目录内，拒绝空路径、相对路径、工作库路径及 symlink/junction；递归清理使用相同边界。7 项隔离测试覆盖这些入口及重启复用。边界修改先在源码副本验证，完整回归后再次核对真实数据库和凭据文件哈希，均保持不变，再启动工作台并执行上述授权采集。

数据库、凭据、恢复快照、测试副本及含本机信息的原始验证记录均未纳入仓库。
