# 知行日常使用 SOP

日常双击桌面的 **知行学习工作台** 或 [start-all.cmd](../start-all.cmd)，打开「今天」。自动整理开启后，采集、续页与目标筛选在程序运行时后台完成。

入口：[今天](http://127.0.0.1:18997/) · [偏好设置](http://127.0.0.1:18997/settings)。项目、知识、复习、完整练习与手动采集在「高级工具」中。

## 默认日常流程

1. 看今天最多三个重点及其与目标的关系；需要核对时展开来源。
2. 在已选好的练习下，用自己的话写解释、例子或成果，点击 **保存输出**。
3. 保存后可展开 **核对要点** 自查。提交记录会保留；自查提示不代表答案已被自动判分。

首次使用时，在偏好设置保存学习档案和模型，在高级工具中保存一次对话范围，再回首页开启自动整理。已有配置直接沿用。每日时间预算为 0 时不会安排练习。

自动整理正常间隔一小时，每天最多三次，连接失败允许一次短暂重试，失败和请求结果不明均计入；每次最多处理 12,000 个 Unicode 来源字符，长材料会渐进接续。当天重点最多三项，输出练习保持稳定。费用仍取决于服务商模型及材料；本地采集和自查不调用模型。

## 可选：在飞书学习

在偏好设置的飞书学习入口点击 **扫码连接飞书**，按页面完成授权与连接。随后点击 **打开飞书私聊**，或用 **手机扫码打开** 进入机器人，再获取绑定码并在私聊中发送 **绑定 验证码**，无需先建群。应用可能仍需在飞书后台发布或通过管理员审核，页面的“已连接”与“扫码完成”分别显示。完整初次配置见 [飞书接入说明](FEISHU-CHAT.md)。

绑定后收到今日练习，直接回答即可；网页的「今天」会显示同一条输出及本地自查提示。也可以发送 **今日练习** 主动获取。**暂停** 停止提醒，**继续** 恢复，**稍后** 延后 30 分钟。默认按档案时区每天提醒一次；已有输出不会重复安排同一道题。

未说明帮助程度时记录为未知；可用 **独立：你的回答** 或 **提示：你的回答** 如实注明。只有知行程序运行且联网时才接收消息和推送；当前第一步聚焦今日练习，思源卡片复习、进度 AI 对话和自适应安排属于后续阶段。

## 高级：手动安排练习

1. 在 **高级工具 → 每日计划** 点 **重新安排今天**；空白计划也可点 **生成今日计划**。
2. 看「下一步」与预计用时，点 **开始处理**。如果是练习，在 **练习与输出 → 练习工作区** 选择对应题目。
3. 先自己思考，再填写 **你的输出**，如实选择 **借助程度**。可补充 URL 证据，点 **提交本次尝试**。
4. 点 **获取模板反馈**，对照评价要点自查。模板反馈只提供检查清单，**不判断答案正确性，不代表已经掌握技能**。
5. 值得保留时点 **转为成果**，在「我的成果」填写标题并点 **保存成果**；只点「转为成果」还没有保存。

提交尝试后，对应练习会记录为完成。知识库为空时也可依据你保存的目标生成模板练习；加入真实知识后，材料才能更贴近你的工作。先完成一项即可，不必先建立完整知识体系。

如果提示「先设置学习目标」，到 **设置 → 学习档案** 填写 **当前目标（每行一条）** 并保存；**每日预算（分钟）** 必须大于 0，设为 0 会暂停计划。初次使用可设 15 分钟。

## 工作时：一个项目，一个接续节点

1. **项目 → 新建项目**，填写 **项目名称** 和 **要完成什么**，点 **创建项目**。目标写成今天能检查的结果。
2. 正常开展你的科研或开发工作；无需为了记录而频繁切换页面。
3. 切换任务或收工前，打开项目，在 **留下接续节点** 中填写 **本次进展**、**下一步**，有阻碍时再填 **未决问题（可选）**，点 **保存节点**。

「下一步」写成下次打开就能执行的动作，例如「比较两组结果，记录三个差异」，不要只写「继续研究」。

## 收工时：只保留值得再用的知识

先选当天最有价值的一至三条，避免把所有对话都当作学习任务。

1. **知识 → 手动记录**，填写 **问题**、**答案**，可选 **所属项目**，在 **手工来源（每行一条 URL 或摘录）** 放原始依据，点 **保存草稿**。
2. 核对内容、来源和适用条件，再点 **接受**。接受表示保留，**不表示事实已核验**；手工 URL 只是引用，不会自动抓取。
3. 需要间隔复习时再点 **同步到思源**。同步是接受后的另一次操作，不是练习的前置条件。
4. 下次进入 **复习**，先独立回忆，勾选 **我已经独立尝试过回忆**，再点 **揭示答案**，如实评分。没有到期卡片时直接做输出练习即可。

## 高级：手动采集与旧定时器

默认自动整理按上面的流程运行。下表说明高级手动能力，原有数据和操作仍可使用：

| 操作 | 什么时候发生 | 是否调用大模型 |
| --- | --- | --- |
| 查看近期对话标题、项目与时间 | 你点击「查看近期对话」或刷新列表 | 否；只读元数据，不授权或采集正文 |
| 同步授权对话、保存来源及候选知识 | 手动点「同步授权对话」，或启用定时同步后按间隔运行 | 否；本地读取和规则提取 |
| 今日计划、界面上的「获取模板反馈」 | 你点击按钮；定时日计划也是模板模式 | 否 |
| 模型出题、模型反馈 | 后端显式请求 `mode: model`，并具备有效配置时 | 是 |

**默认同步间隔为 60 分钟，但定时任务默认关闭。** 当前是否启用，以本机设置页为准。服务运行期间才可能执行定时任务；程序内部每 15 秒检查一次定时条件，不表示每 15 秒分析一次对话。

自动整理开启后，会按职业方向、学习目标和技能调用模型提炼有来源的重点；自动采集只保存来源，不逐条建立回答草稿。高级手动同步仍保留原始摘录行为；旧定时采集在自动整理开启期间让出执行，原设置值保留。

来源按身份、内容摘要和档案版本做增量处理，自动整理不会因刷新首页而调用模型。关闭自动整理后不再调度；已保存的内容和输出仍可查看。

日常不用查找或记住线程 ID：

1. 进入 **对话采集**，点击 **查看近期对话**。默认列出最近 **7 天、最多 20 条** 对话的标题或短预览、项目路径和时间；打开页面不会主动浏览未授权列表。
2. 按标题勾选需要的对话，点击 **保存所选对话**。查看或勾选都不会采集正文；保存才会授权并启用这些对话的采集。尚未保存的新选择不能直接同步。
3. 点击 **同步授权对话**。同一对话的授权保留，之后继续这段对话时直接同步即可；新建对话后重新查看近期列表并勾选。
4. 需要按整个开发项目授权，或填写排除项时，展开 **高级设置**。项目目录按 Codex 会话的实际工作目录匹配，覆盖其子目录；关联产品项目不代替该授权。排除规则优先。

定时频率也在网页控制：

1. 在 **设置 → 飞书与定时任务** 开启 **启用定时任务** 和 **定时同步 Codex**，将 **Codex 同步间隔（分钟）** 设为 **5～1440** 的整数，点 **保存可选设置**。只保存所选对话不会打开定时任务。
2. 每日模板计划另由 **定时生成模板日计划** 与 **每日计划时间** 控制；**补做最近一个错过周期** 最多补最近一次，不逐个补跑历史时段。关闭服务后定时任务也停止。

CLI 不支持时可用 **手动导入对话**。只授权需要整理的范围。首页和偏好设置中的「自动整理」独立控制新的目标提炼流程。

长会话初次采集可能分批完成。出现 **本批完成（还有更多）** 时，已处理内容和读取进度已经保存，点击 **继续采集** 读取后续部分；最终显示 **任务完成** 才表示本次扫描结束。批次失败后重试会使用最近成功保存的进度，服务正常重启后也可续采。已有来源按消息身份和摘要去重，不需要重新填写 ID 或手工拆分对话。

## DeepSeek 配置

2026-10-28 核对的官方低价型号是 **deepseek-flash**。在 **设置 → 可选模型服务** 填写：

| 字段 | 内容 |
| --- | --- |
| API Base URL | `https://api.deepseek.com` |
| 模型名称 | `deepseek-flash` |
| API Key | 只在本机设置页填写你自己的 DeepSeek API Key |

需要实际调用模型时，再勾选 **启用模型处理** 及外部处理授权，点 **保存模型设置**。本机已经配置好时，无需重复填写；源码仓库不包含这些本机凭据。保存成功只表示配置已保存，实际可用性仍需请求验证。API Key 只保存在本机凭据库，不提交到 Git。

对官方 `api.deepseek.com` 的请求关闭思考，单次输出上限为 **2048 token**。自动整理另有每天三次尝试上限；这不是服务商账户总费用上限。已运行的旧服务需要正常重启后才会加载新功能。没有 Key 时仍可使用高级手动与模板功能。

官方参考：[接入与模型名称](https://api-docs.deepseek.com/) · [请求参数](https://api-docs.deepseek.com/api/create-chat-completion/) · [当前价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。模型、价格及套餐以后可能变化，以服务商页面为准。

## 启动、备份和常见情况

- 页面能打开时直接使用。需要重进时双击桌面的 **知行学习工作台** 或 [start-all.cmd](../start-all.cmd)，入口检查服务后补起缺失进程，再打开网页。
- 思源连接异常时，手动记录、模板计划和练习仍可使用；原生卡片复习与同步需要恢复连接。专用思源入口固定使用 `19006`，不要用另一个内核同时打开同一工作区。详见 [运行说明](../runtime/RUNBOOK.md)。
- **设置 → 导出数据** 保存产品记录；导出不包含连接凭据，也不代替思源工作区备份。
- 文本框中的草稿不等于服务端已保存；以「提交本次尝试」「保存成果」「保存节点」等操作成功为准。
- 查看近期对话时若提示「Codex 尚未提供已验证的安全标题列表能力」，表示当前 CLI 版本的只读协议尚未被适配器确认。保留已有授权，更新兼容适配后重试即可；重新填写线程 ID 或扩大目录范围无法解决这个错误。
- 关闭浏览器只关闭页面，后台仍可能运行。需要退出知行时，在原知行运行窗口按 **Ctrl+C**；思源从自己的界面正常退出。停止服务后数据仍保留。
