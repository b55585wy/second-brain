# 飞书学习卡片

卡片把学习动作放在原消息中：**回答 → 看建议 → 保存建议或暂不采纳 → 记忆闪卡**。卡片界面由 Kimi CLI 实现，业务、存储和评分由 Codex 接入。

## 启用一次

在知行的 **偏好设置 → 飞书学习 → 学习卡片** 点击 **扫码启用学习卡片**，用飞书为已经连接的机器人补充卡片回调授权。沿用当前机器人与私聊绑定，不必建立群聊、查询 ID 或重新填写密钥。

扫码完成说明授权流程结束。页面还会显示是否收到过当前绑定下的有效按钮操作；需要在飞书点一次卡片按钮，才能确认回调实际连通。如果租户要求发布应用或管理员审核，先完成飞书官方页面上的步骤。

知行后台需要运行。关闭网页不影响后台，关闭后台或电脑则无法即时收发。

## 每个按钮做什么

| 操作 | 结果 |
| --- | --- |
| 提交回答 | 保存本次回答；可注明独立完成或借助程度。卡片表单限 1000 字，长回答可直接发私聊文本。 |
| 查看建议 | 查看这次回答的“已做到、待改进、下一步”。已完成的建议直接复用；准备中显示状态。 |
| 保存建议 | 收藏为知行中已有的学习成果，带上原练习的目标和来源。重复点击不会重复创建成果。 |
| 暂不采纳 | 记录当前选择，保留回答、建议及已经收藏的成果；不会删除历史。之后仍可重新保存。 |
| 记忆闪卡 | 进入思源原生到期复习；没有到期卡时，可以明确选择用本次学习重点制作一张。 |
| 翻面 | 先自己回忆，再显示答案。翻面前不能评分。 |
| 忘记／困难／记得／轻松 | 记录本次记忆自评，交给思源原生调度；评分确认前不继续重复发送。 |

用学习重点制作闪卡，需要兼容的思源连接。点击制作表示你选择保留这条知识，内容仍标为未核验。新卡沿用已有同步与复习机制，不额外调用模型。

保存的建议可在网页 **高级工具 → 练习与输出 → 成果** 中查看。默认先收进知行；本轮没有把所有建议自动同步到思源。

## 次数与失败

新回答的自动点评由 **偏好设置 → 自动点评** 控制，默认关闭，开启后的初始上限为 3 次/天，可设置为 0–20 次。它与自动整理对话的每日额度分开。调用失败或结果不明也计入次数；不会悄悄再次付费请求。旧回答只有明确请求时才补点评。

翻面、查看已完成建议、保存或暂不采纳、已有闪卡复习均不额外调用模型。模型不可用时仍保留回答与本地自查；本地自查不代表正确性评估。AI 建议和记忆自评也不能证明事实已经核实或长期能力已经掌握。

卡片失效、题目或来源变动时，先刷新状态或发送“今日练习”。结果不明的保存、发送和评分不盲目重做。已保存的原始回答保留。

“稍后”表示把提醒延后约 30 分钟；“暂停”表示停止主动提醒，已有回答继续保留。这两项属于提醒控制，不占学习卡片的主要按钮。

## 技术边界

使用飞书 Card 2.0 与当前应用的 `card.action.trigger` 回调。按钮绑定应用身份、私聊用户、原消息和当前题目，回调先入队，模型与思源操作在后台处理。授权成功不能代替真实按钮连通验收。

原回答、反馈、收藏成果和当前建议选择进入正常备份；应用密钥、私聊绑定、卡片回调令牌及待执行任务不会作为可恢复权限导出。导入备份不会自动开启飞书或模型调用。
