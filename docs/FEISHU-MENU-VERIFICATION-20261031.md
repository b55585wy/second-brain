# 飞书菜单验收（2026-10-31）

## 问题与范围

用户发送“今日练习”后没有聊天反馈。只读对照确认产品已收到并识别该命令，随后一次learning_card投递进入uncertain；没有确认消息标识，也没有自动重试。旧代码只记录本地错误，没有补充聊天提示。现有记录不能证明当时的具体平台错误或是否实际送达。

0.6.0增加四入口菜单，命令优先于讨论和作答处理；菜单在没有今日题目时也可打开。菜单中的今日练习导航更新已确认的同一条消息，不重启旧uncertain操作。只有题目更新成功确认后才建立回答关联。查看已有建议和状态不调用模型，记忆闪卡沿用现有复习流程。

明确请求的卡片在终态失败或结果未知时创建至多一条文字提示，不重发原卡片，不对提示递归补提示。发送层只将有效正整数业务码及既有权限／限流码认作明确拒绝，保留安全数字providerCode；超时、无业务码HTTP错误和残缺响应仍为未知。原始SDK错误、请求和响应正文不进入错误摘要。
