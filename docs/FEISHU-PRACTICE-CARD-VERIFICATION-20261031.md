# 题目卡片修复验收（2026-10-31）

## 真实故障与修正

0.6.0菜单卡片首次投递被平台接受。随后用户真实点击“今日练习”，题目更新被飞书以230099拒绝，菜单消息仍停留在旧版，不能提交题目回答。本记录保留这次失败，不用菜单已发送或模拟测试替代题目更新的实际验收。

已核对[官方下拉单选组件定义](https://open.feishu.cn/document/uAjLw4CM/ukzMukzMukzM/feishu-cards/card-json-v2-components/interactive-components/single-select-dropdown-menu.md)：它没有label字段。0.6.1由实际Kimi CLI移除该字段，改为下拉框前的独立可见说明；输入框label、默认unknown、五个选项、提交格式及其他卡片保持。官方[表单示例](https://open.feishu.cn/document/uAjLw4CM/ukzMukzMukzM/feishu-cards/card-json-v2-components/containers/form-container.md)中的选择组件可随表单批量提交，本次不增加单独回调。

单独调用CardKit进行合成格式校验时被99991672权限错误拒绝，没有获得格式校验结论。没有为此增加权限或要求用户重新配置；修复以原有消息更新接口的实际接受结果为准。

## 受限恢复

`POST /api/v1/feishu-chat/cards/:id/refresh-known-failed`使用本地客户端标记、operationId和expectedVersion。只有原菜单已确认送达、当前题目与绑定和来源有效、最新更新明确失败、有真实menu_today点击及成功任务记录时才接受。发送中或结果未知的更新不能走此入口。

恢复创建独立的刷新意图，在同一条已确认消息上发布新版本，不改变旧失败、旧事件或旧未确认记录。平台确认新版本后才建立回答关联，确认前不能提交。没有伪造用户回调或练习回答，不调用学习模型。
