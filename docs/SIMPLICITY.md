# 降低认知负荷

本版本的目标是：配置一次后，用户每天打开首页即可学习和输出，不必维护采集、分页、摘录队列。

## 事实与待验证假设

现有程序已具备授权采集、持久任务、模型接口、档案和输出记录，可以复用。旧流程要求用户选择、保存、同步、继续采集，再筛选大量摘录。用户能投入的学习时间由档案中的每日预算约束，材料数量增加不会自动增加可用时间。

减少这些管理动作可以直接验证；是否降低主观负担并改善长期学习，仍需实验验证。不能用生成条数或点击减少替代学习成效。

## 交付标准

- 已配置用户只需一次开启自动整理；日常的同步、续采、刷新和练习选择操作为零。
- 首页最多展示三个与档案目标相关的重点，每个给出入选理由和可展开的来源。
- 每天直接给出一个符合时间预算的独立输出练习；预算为零时不安排练习。
- 同日练习和已提交输出保持稳定，刷新、轮询和新的整理批次不清空正在写的内容。
- 新一天优先安排尚未安排过的有效重点，没有新内容时回顾最久未安排的重点；安排过不表示已经掌握。
- 日常主导航只保留“今天”和“偏好设置”；旧项目、知识、复习、练习、采集和计划入口保留在高级工具中。
- 服务器成功响应是内容依据；请求失败时保留最近成功内容，目标或范围变化后不在客户端复活已失效内容。

## 后台行为

程序运行期间自动处理已授权对话。每次采集有上限，未完成时后台接续；完成一轮后每小时检查。自动采集不再为每条回答建立摘录草稿。

自动提炼只处理当前授权采集收据覆盖的来源，结合职业方向、学习目标和技能筛选内容。每次来源文本最多 12,000 个 Unicode 字符，长材料保留未处理尾部。正常整理间隔一小时，每天至多三次；连接失败后允许一次短暂重试，所有失败和请求状态不明也计入次数。关闭后不再调度，已有学习内容仍保留。旧手动能力继续可用。

模型整理带来源和生成信息，不能自动视为事实核验或知识掌握。练习由用户独立作答；首页自动提供本地自查提示，不额外调用模型判分。原始摘录和完整管理能力可在高级工具中查看。
