## 日常启动

1. 双击当前本机桌面的 **知行学习工作台**，或项目根目录 [start-all.cmd](../start-all.cmd)。入口检查并补起专用思源和知行，再打开网页；已运行的服务复用，不停止进程。
2. 知行首次启动后保持运行窗口开启，按 **Ctrl+C** 停止。复用既有知行时本次入口打开页面后退出，原服务继续运行。单独控制时仍可使用 [open-siyuan.cmd](../open-siyuan.cmd) 和 [start.cmd](../start.cmd)。思源入口只调用已安装的官方应用并传入专用 workspace 和固定 port。
3. 知行 **设置 → 思源笔记** 保持 **使用本地运行时连接清单**。当前 connection.json（本机留存：`connection.json`） 是实际检查后的元数据，不是示例；连接检查已通过。
4. 思源使用后从自己的界面正常退出。重新打开专用工作区时继续用 open-siyuan.cmd；工作空间菜单默认可能分配其他端口，若已经这样打开，先正常关闭该独立窗口，再使用固定入口。不要同时用两个内核打开同一个工作区。

当前本地思源访问策略允许空令牌；错误的非空令牌会被拒绝，本轮未读取、创建或发送真实 API Token。若另行开启认证，需要按思源实际认证配置，在本机产品设置中填写凭据；不要发到聊天。连接成功不由配置保存或清单存在推定，仍以实际检查结果为准。
